# VarAC Interoperability Research

Objective:
Develop an independent cross-platform Rust application
capable of communicating with existing VarAC clients.

Research targets:
- VARA modem TCP interface
- Connection and handshake behavior
- Direct chat message framing
- Broadcast messages
- VMail messaging
- File transfers
- Error handling and acknowledgments

Use publicly available specifications and observed
interoperability behavior where possible.

Retain original licensing information and respect
applicable software license restrictions.
